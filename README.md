<h1 align="center">ONETAKE Account Checker</h1>
<p align="center">
  Программа для быстрой проверки всех Steam-аккаунтов игрока<br>
  на VAC-баны и активные наказания на ONETAKE.
</p>

> [!IMPORTANT]
> ONETAKE Account Checker (в данный момент) не входит в официальный список программ для проверки.\
> Программа создаётся независимо от ONETAKE и не связана с проектом напрямую.

---

## Функционал
- 🔍 **Автоматический поиск** всех Steam-аккаунтов, в которые заходил пользователь
- 🚫 Проверка **VAC-банов** и **наказаний на ONETAKE**
- 📊 **Вывод таблицы** со всеми аккаунтами
- 📁 Экспорт результатов в `.txt`
- 🌐 Быстрый переход к профилю ONETAKE

---

## Использование
После запуска утилита:

1. Найдёт папку Steam.
2. Соберёт список аккаунтов.
3. Спросит режим сканирования.
4. Просканирует аккаунты и покажет резлуьтат.

---

## Установка
1. Скачать последний релиз со страницы [**Releases**](../../releases/latest).
2. Запустить `ONETAKE-AccountChecker.exe`.

**Никаких зависимостей, установок и Python не требуется** — всё уже собрано в один `.exe`.

> [!IMPORTANT]
> При первом запуске Windows или антивирус может выдать предупреждение, потому что файл не подписан цифровым сертификатом. Исходный код программы открыт для изучения и все обнаружения являются ошибочными.
